# THE FOUR — FIND YOUR FOUR

Campaign platform prototype for **The Four: No One Fights Alone**, proposed and produced digitally by WAWO Brand House.

## Current stack
- Next.js App Router
- React
- TypeScript
- Mobile-first responsive UI
- Browser-native image processing with Canvas
- Native share / WhatsApp share fallback
- Prototype invite links using a Four code
- Prototype consent/registration step

## Product journey
**FIND → CREATE → SHARE → WATCH**

1. A user creates a Four.
2. Four photos are uploaded or captured.
3. The browser generates a personalised campaign image.
4. The user shares the image and Four link.
5. The invited members join the Four.
6. The production version connects registration to cinema selection, ticketing and rewards.

## Production phase still required
- Persistent backend/database
- Cloud image storage
- Server-side/approved personalised artwork generation
- Unique Four records and invite/member tables
- Consent records and campaign messaging
- Cinema/showtime integration or approved ticketing handoff
- Reward qualification / redemption
- Campaign dashboard
- Final official movie artwork and brand assets

## Important
Movie artwork, talent likenesses, ticketing integrations, privacy language and reward mechanics require approval from the relevant rights holders and campaign partners.
